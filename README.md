# Atlas Tutorial

A guided, hands-on tour of Atlas Explore, Raise and Scout by SportsTechX. It runs
the real Atlas product UI on made-up sample data: no backend, no database, no
sign-in, no paywall, and nothing leaves the browser.

```bash
npm install
npm run build     # typecheck + production build
```

No environment variables are needed. See [lib/sandbox/README.md](lib/sandbox/README.md)
for how the tutorial works and how to write tour steps.
